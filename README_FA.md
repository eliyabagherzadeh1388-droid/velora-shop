# Vynexa Stars — بسته انتقال به GitHub و FadeHost

این بسته شامل همان سورس فعلی ربات با نام `bot.py` و فایل وابستگی‌هاست. منطق ربات و متن‌ها و دکمه‌ها و ایموجی‌های پیش‌فرض سورس تغییر داده نشده‌اند.

## فایل‌ها
- `bot.py` — سورس اصلی، کپی‌شده از فایل ارسالی بدون تغییر محتوای کد.
- `requirements.txt` — وابستگی لازم.
- `.env.example` — نمونه متغیرهای محیطی؛ مقادیر محرمانه داخلش قرار نداده‌ایم.

## راه‌اندازی در FadeHost
1. محتویات ZIP را در ریشه مخزن GitHub آپلود کن.
2. دستور نصب وابستگی‌ها: `pip install -r requirements.txt`
3. دستور اجرا: `python bot.py`
4. متغیرهای Environment را از برنامه فعلی FadeHost عیناً منتقل کن؛ فقط مقدار `ADMIN_IDS` را مطابق آیدی عددی اکانت جدید تنظیم کن.

## خیلی مهم — حفظ تنظیمات و ایموجی‌های پریمیوم
ایموجی‌های سفارشی/پریمیوم انتخاب‌شده و تنظیمات پنل در دیتابیس SQLite ذخیره می‌شوند، نه داخل `bot.py`. فایل دیتابیس فعلی (`vynexa_stars.sqlite3` یا مسیری که در `DB_PATH` تنظیم شده) در فایل ارسالی شما وجود نداشت؛ بنابراین عمداً دیتابیس خالی نساختیم و داخل ZIP نگذاشتیم تا اطلاعات قبلی ناخواسته جایگزین نشود.

برای اینکه دقیقاً همان ایموجی‌های پریمیوم، قیمت‌ها، متن‌ها، لینک‌ها و تنظیمات قبلی باقی بمانند، باید دیتابیس فعلی را از فضای ذخیره‌سازی برنامه فعلی نگه داری/منتقل کنی و `DB_PATH` را به همان فایل پایدار وصل کنی. اگر FadeHost برنامه فعلی را با همان فضای ذخیره‌سازی و همان فایل دیتابیس ادامه دهد، لازم نیست دیتابیس را از نو بسازی.

**توکن ربات و `CHALLENGE_SHARED_SECRET` را داخل GitHub یا ZIP عمومی قرار نده.** آن‌ها را فقط در Environment Variables خصوصی FadeHost وارد کن.
